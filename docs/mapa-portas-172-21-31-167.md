## `.env` correspondente

Valores que o compose **já** lê. Gateway e n8n no host ainda estão fixos em `3000:3000` e `5678:5678` — no servidor use o override abaixo, ou altere o mapeamento na hora do deploy.

```ini
# --- PET neste host (172.21.31.167) ---
POSTGRES_HOST_PORT=5534
PWA_PORT=3802
DASHBOARD_API_PORT=3803
DASHBOARD_FRONT_PORT=3804

# URLs internas (não mudar: são nomes da rede Docker)
GATEWAY_URL=http://whatsapp-gateway:3000
N8N_WEBHOOK_URL=http://n8n:5678/webhook/whatsapp
N8N_PWA_WEBHOOK_URL=http://n8n:5678/webhook/pwa-chat
PWA_PUBLIC_URL=http://pwa:8080

# Sem Cloudflare neste host
CLOUDFLARE_TUNNEL_TOKEN=
CLOUDFLARE_URL=
COMPOSE_PROFILES=
```

Override para as duas portas ainda hardcoded (arquivo extra, não substitui o compose principal):

```yaml
# docker-compose.franca.yml
services:
  postgres:
    ports:
      - "127.0.0.1:${POSTGRES_HOST_PORT:-5534}:5432"
  whatsapp-gateway:
    ports:
      - "127.0.0.1:3800:3000"
  n8n:
    ports:
      - "127.0.0.1:3801:5678"
  pwa:
    ports:
      - "${PWA_PORT:-3802}:8080"
  cloudflared:
    profiles: ["cloudflare"]
  dashboard-api:
    ports:
      - "127.0.0.1:${DASHBOARD_API_PORT:-3803}:3333"
  dashboard-front:
    ports:
      - "127.0.0.1:${DASHBOARD_FRONT_PORT:-3804}:3000"
```

Subida no servidor:

```bash
docker compose -f docker-compose.yml -f docker-compose.franca.yml up -d --build redis postgres n8n pwa whatsapp-gateway
```

Não incluir `cloudflared`. Não incluir `dashboard` até existir a pasta `Dashboard-PetSaude/`.
